# Manual Pengguna – Sistem Permohonan JOC FKTEN

Interactive user manual (slides) for the JOC application system of the Fakulti Kejuruteraan & Teknologi Elektronik (FKTEN), Universiti Malaysia Perlis.

- `index.html` – the slide manual (Bahasa Melayu). Arrow keys / swipe to move, **O** for contents, **F** for full screen.
- `demo/` – clickable demo of the system with **sample data only** (stored in the browser; no real data, no emails).
- `assets/shots/` – screenshots taken from the demo.

No build step: open `index.html` in a browser or view it on GitHub Pages.
